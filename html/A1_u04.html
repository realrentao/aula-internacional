Unidad 4 · ¿Cuál prefieres?

Hacer la lista de cosas que necesitamos para un fin de semana fuera y comprar en tiendas · 列出周末出行所需物品并在店里采购
交际：辨认物品·表达需求·购物·谈偏好 语法：指示词·tener que·ir·preferir 词汇：数字100+·颜色·服装·日用品

💬 Diálogos · 核心对话

同学们在筹备周末出游的购物清单，然后在服装店里挑选。点击任意西语句子可听发音。

Identificar objetos y expresar preferencia · 辨认物品与表达偏好

Pregunta¿Qué es esto? — 这是什么？
RespuestaEs una camisa. — 是一件衬衫。
Pregunta¿Cuál prefieres, esta camisa o esa? — 你更喜欢哪件，这件还是那件？
RespuestaPrefiero esta camisa azul. — 我更喜欢这件蓝衬衫。

Expresar necesidad · 表达需求

Pregunta¿Qué necesitas para el fin de semana? — 周末你需要什么？
RespuestaNecesito una mochila y unas zapatillas. — 我需要一个背包和一双运动鞋。
RespuestaTengo que comprar una chaqueta. — 我得买一件外套。

Comprar en tiendas · 在店里购物

Cliente¿Cuánto cuesta esta camisa? — 这件衬衫多少钱？
VendedorCuesta cien euros. — 一百欧元。
Cliente¿Tiene esta camisa en rojo? — 这件衬衫有红色的吗？
VendedorLo siento, no tenemos rojo, pero tenemos azul. — 抱歉，没有红色，但有蓝色。

📚 Gramática · 语法点

Los demostrativos · 指示词

表「这/那」：este/esta（这个，近）、estos/estas（这些）；ese/esa（那个，中远）、aquel/aquella（那个，更远）；esto（这个，指事物无性数）。例：Prefiero esta camisa.（我更喜欢这件衬衫。）

El / la / los / las + adjetivo · 冠词 + 形容词

形容词通常放在名词后，并与名词性数一致：la camisa azul（蓝衬衫）、los zapatos negros（黑鞋）。注意颜色词多数不分阴阳（azul, gris, marrón），但 rojo→roja、negro→negra 等要变。

Qué + sustantivo / cuál / cuáles · 提问

¿qué + 名词? 问「哪个（事物）」：¿Qué camisa prefieres?（你喜欢哪件衬衫？）。¿cuál/cuáles? 问「哪一个/哪些」（从已知选项中选）：¿Cuál prefieres?（你更喜欢哪一个？）

Tener que + infinitivo · 必须做

表「得/必须」。变位 tener：tengo / tienes / tiene / tenemos / tenéis / tienen。例：Tengo que comprar una chaqueta.（我得买件外套。）

El verbo ir y el verbo preferir · ir 与 preferir

ir（去）不规则：voy / vas / va / vamos / vais / van。例：Voy a la tienda.（我去商店。）preferir（更喜欢，e→ie）：prefiero / prefieres / prefiere / preferimos / preferís / prefieren。

☕ Café Cultural · 文化角

Comprar en España · 在西班牙购物

西班牙很多城市有 el mercado（市场）和 el centro comercial（商场）。传统商店午后有 la siesta 式午休，傍晚才重开；大超市则全天营业。问价常说 ¿cuánto cuesta?（多少钱？），结账用 tarjeta o efectivo（刷卡或现金）。

中文对照：中文数字「两百」西语用 doscientos（字面「二百」），「一千」是 mil（无复数 s）。
