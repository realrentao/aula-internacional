📚 Gramática · 语法点

La forma impersonal con se · se 无人称句

用 se + 动词第三人称 表示「人们（泛指）……」，不指明主语。例：Se come a las dos.（人们两点吃饭。）/ Se habla español aquí.（这里说西班牙语。）/ Se hace con arroz.（用米做。）

Los verbos poner y traer · poner 与 traer

poner（放）：pongo / pones / pone / ponemos / ponéis / ponen。traer（带来，不规则 go 型）：traigo / traes / trae / traemos / traéis / traen。例：Pongo la mesa.（我摆桌。）/ Traigo la paella.（我把海鲜饭带来。）

Los pronombres de OD (lo, la, los, las) · 直接宾语代词

替代直接宾语（事物），位于变位动词前：lo（阳单）、la（阴单）、los（阳复）、las（阴复）。例：La paella la preparo los domingos.（海鲜饭我星期天做——la 指代 la paella。）/ El pan lo compro en la panadería.（面包我在面包店买。）

☕ Café Cultural · 文化角

Las tapas y la hora de comer · 小吃与用餐时间

西班牙饮食文化少不了 las tapas——配酒的小份菜肴，朋友间常「ir de tapas」（一家家转着吃小吃）。la comida（主午餐）约 14–15 点，la cena 约 21 点，比中文习惯晚很多。周末家庭聚餐常做 paella。

中文对照：中文「做菜」主语是人；西语常用 se hace 无人称，强调做法本身而非谁做。
