📚 Gramática · 语法点

El imperativo afirmativo · 命令式肯定

四种形式：tú / vosotros、usted / ustedes。

原形túvosotrosustedustedes
comprarcompracompradcomprecompren
comercomecomedcomacoman
vivirvivevividvivavivan

tú 形式由现在时去掉词尾 -s 得到（compras → compra）。带 e→ie / o→ue / e→i 变化的动词保留变化（piensas → piensa, duermes → duerme, pides → pide）。几个 tú 不规则形式：pon, ten, sé, haz, sal, ven, di, ve。代词置于动词之后并与之连写：Lávate bien los pies e hidrátalos cada día.（每天好好洗脚并滋润它们。）

El verbo doler · 疼痛

结构：me / te / le / nos / os / les + duele（单数名词）/ duelen（复数名词）。

例句中文
Me duele la cabeza.我头疼。
Le duelen los pies.他脚疼。

相关表达：tener + dolor de + 部位；tener + tos / fiebre / frío / náuseas；estar + mareado / resfriado / cansado / pálido。

Ser / estar · 识别描述与临时状态

ser 用于身份、来源、职业、性格等 permanente / objetivo：Carlos es un amigo mío. Yuri es sueco. Sandra es dentista.estar 用于临时、主观或当下的状态/位置：El novio de Tania está un poco raro últimamente: está triste, de mal humor, y está muy delgado.

注意：Es impaciente.（他一向没耐心）vs Está impaciente.（他这会儿不耐烦）。过去分词作形容词只用 estar（La puerta está abierta）；bien / mal 也只与 estar 连用（Está muy bien）。

Dar consejos · 给建议

无人称：Lo mejor es hacer deporte. / Va muy bien desayunar fruta. 人称：Tienes que comer menos. / Debes hacer más deporte. / Deberías andar más. / Puedes hacer una dieta. / Intente comer menos dulces.

☕ Café Cultural · 文化角

Los españoles y el deporte · 西班牙人与运动

据西班牙教育、文化与体育部的调查，如今西班牙人比十年前更常运动；多数人运动并非为了享受，而是为了放松、对抗压力，当然也为了estar en forma（保持身材）。

有趣的是，热门运动变了：足球与游泳仍居前列，但新趋势是大多数人做体操（gimnasia，在家或健身房）。近二十年流行起一些新运动：el pádel（板式网球，20 世纪 60 年代起源于墨西哥，近几十年在西语国家大热）；la zumba（有氧操，起源于哥伦比亚，伴随 salsa、cumbia、merengue 节奏，据说既能减肥又能塑形）。

中文对照：中文里我们也说「健身 / 塑形 / 保持健康」；西语的 estar en forma 正是「处于好状态、身材好」之意。
